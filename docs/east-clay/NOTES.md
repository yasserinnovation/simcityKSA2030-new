# Eastern clay-country enrichment

Jubail's earlier generic tank-farm/processing modules are replaced with original procedural geometry: six distillation columns with service platforms and ladders, eight storage tanks, three open-rim cooling towers, eleven supported pipe runs, horizontal vessels, pump skids and a striped stack. Three animated pumpjacks and soft cooling steam make the site active. Factory halls, port cranes and cargo ships remain. This is an illustrative industrial composition inspired by the user's supplied images, not a reconstruction of a named refinery.

71 Gulf neighbourhood plots add cream, peach and turquoise blocks, blue rooftop panels, windows and trees outside existing project/road clearances. 23 corniche modules add paving, benches and palms. Dhahran receives five Ithra-inspired stone-like forms, Khobar its coastal water tower, and Hofuf an Ibrahim Palace-inspired enclosure, domed hall and minaret. Sources: [Ithra's official architecture description](https://www.ithra.com/en/about-ithra), [official Khobar corniche reference](https://partner.visitsaudi.com/en/content-hub/visual-assets/?query=khobar+corniche), [Ibrahim Palace](https://www.visitsaudi.com/en/al-ahsa/attractions/qasr-ibrahim). Sites follow the existing illustrated regional plan; no survey-accuracy claim is made.

Animation uses cosmetic time and respects reduced-motion preferences. It is hidden in picking/shadow passes. Static landmark and industrial geometry retains the normal renderer picking/shadow pipeline. Named scenic labels support English and Arabic. Project IDs, footprints, roads, simulation costs and save schemas are unchanged. The classic renderer retains its earlier geometry.

Verification: six matching 1440 × 900 daylight/camera captures, seven city/project targets with six sampled picking hits each, unchanged local storage and renderer project state after preview, no browser errors. All seven gameplay suites passed, and the existing render smoke checks passed for both renderers. Raw results: after/results.json. No independent performance or hardware claim is made.

Code: east-clay.js, world-cosmetics.js, engine.js and boot.js. Reproduce with the local server on port 8016 and node tools/check-east-clay.js after. Captures freeze decorative time; run the game to see motion. Reference images guide the style but are not shipped as textures or copied pixels.
