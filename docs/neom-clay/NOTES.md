# NEOM visual pass

Original geometry in `neom-clay.js`, loaded through the existing boot pipeline. The Line's previous repeated grey model is replaced by two 540-panel walls with dune/sky colours, 16 garden bridges and cream caps. Three stacked ring gardens and a hexagonal atrium take inspiration from the supplied fantasy-city references. These are decorative concepts, not claims about official NEOM buildings or construction progress. Facade colours suggest reflections; no real-time environment reflection is claimed.

Oxagon retains its established project/coast position and octagonal structure, with six stepped innovation terraces, three additional cranes, containers and turquoise dock lanes. Hydrogen gains four connected storage tanks. Sindalah gains a garden promenade and pool. Tabuk gains clay neighbourhoods where layout clearance allows.

Trojena's enclosing six-peak ring hid its lake in the standard camera view. Five lower peaks now frame the northern half; five new lakeside lodges, a promenade and a valley cableway leave the foreground open. Four moving cabins are cosmetic only and respect reduced-motion preferences. Static architecture uses the existing shadow and picking pipeline; moving cabins render only in the main pass.

Official design context: [THE LINE](https://www.neom.com/en-us/whatistheline), [NEOM regions](https://www.neom.com/en-us/regions). Locations remain those of the existing illustrative game plan; this is not a surveyed geographic or engineering model.

Verification: six matching fixed-time, fixed-camera before/after views; seven project/place targets with six GPU pick samples each; no browser errors; preview leaves saved storage and project states unchanged. Results are in `before/results.json` and `after/results.json`. All seven gameplay test suites and both renderer smoke tests passed. No external assets, downloads or paid provider jobs were used.
